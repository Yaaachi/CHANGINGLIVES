SECURE EVENT MANAGEMENT

Manage events through GitHub

There is no public password or server to maintain. Only people with authorised write access to your GitHub repository can publish changes. GitHub handles sign-in, access permissions and revision history.

Publish an event

  1. Sign in to GitHub with an account authorised to edit this website.
  2. Open events.json in your website repository and choose the pencil icon to edit.
  3. Add a new event with a unique ID, title, date, location, description, image filename and optional RSVP URL.
  4. Commit the change. Your published site will show the event after the deployment finishes.

Add a poster or remove an event

Upload JPG, PNG or WebP posters into the same root directory as index.html, then use that exact filename in events.json. To remove an event, delete its entry and commit. Do not put confidential information into events.json.

This static approach does not offer a password-protected upload form inside the website. GitHub is the secure editing interface; a browser-based admin dashboard with direct uploads would require an authentication and storage service.
